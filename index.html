Get started in 3 steps

1

Install and start Shizuku

Shizuku lets FPS Meter read frame data safely. Start it with Wireless debugging (Developer options).

Get Shizuku

2

Install FPS Meter

Download the APK above and allow installs from your browser when Android asks.

3

Press Start and play

Open FPS Meter, allow Shizuku and the overlay, press Start, then open a game you picked.

After a phone restart, start Shizuku again.

Good to know

  • FPS comes from the system's frame data and can differ slightly from other tools.
  • CPU and GPU temperature depend on your phone. Sensors that are not available are hidden.
  • Some games may not report frames. FPS Meter measures only the apps you choose.
  • The app uses the internet only to check for updates. Only install APK files from sources you trust.
